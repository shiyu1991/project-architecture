# 使用示例

> 覆盖本 Skill 的典型使用场景：每个示例包含「触发语 → 执行过程 → 输出」三元组。
> 按需加载，用于理解本 Skill 的实际工作方式。

---

## 示例 1：技术小白全流程立项（引导模式）

**触发语：**
> "我想做一个宠物寄养小程序，但我不懂技术，帮我从头开始。"

**执行过程：**

1. 识别用户类型 → 引导模式（全程大白话，每层给"推荐项 + 一句人话解释"）
2. 规模分级 → 有支付与外部用户 → L 级门禁
3. 项目类型判定 → 小程序/移动端 → 走移动端选型流程
4. 需求分析 → 输出领域模型草图（用户/宠物/订单/寄养店/支付）
5. 逐层交互式选型（每轮一个 `ask_followup_question`，确认后重新 web_search）
6. 输出技术栈汇总表，用户确认后初始化

**输出：**

```
## 技术栈选型结果汇总
| 层 | 选型 | 版本 | 选择理由 |
|----|------|------|----------|
| 移动端-主框架 | UniApp | x.x（实时查询） | 一套代码发小程序+H5 |
| 移动端-语言 | TypeScript | - | 类型安全，与 Vue 生态一致 |
| 后端-运行时 | Node.js | LTS | 前后端同语言，生态成熟 |
| 后端-框架 | NestJS | x.x（实时查询） | 模块化，适合业务增长 |
| 后端-数据库 | MySQL | x.x（实时查询） | 通用业务关系型数据 |
| ... | ... | ... | ... |
```

## 示例 2：产品经理 PRD 立项（产品模式）

**触发语：**
> "这是我们团队的产品 PRD，帮我梳理业务并立项。"

**执行过程：**

1. 识别用户类型 → 产品模式（聚焦业务，输出领域模型草图）
2. 需求分析 → 业务层 → 领域模型层 → 应用服务层
3. 输出领域模型草图 + 用户核心流程，用户确认
4. 技术选型只给结论清单和理由摘要，不逐层打断
5. 输出技术栈汇总 + 初始化计划

**输出：**

```
## 领域模型草图
### 核心领域
| 领域 | 描述 | 优先级 |
|------|------|--------|
| 订单 | 商品购买全流程 | P0 |
| 库存 | 商品库存管理 | P0 |
...
### 核心业务流程
流程1: 下单 → 校验库存 → 扣减库存 → 生成订单 → 支付 → 通知
...
```

## 示例 3：开发者快速选型（专家模式）

**触发语：**
> "帮我初始化一个 React + NestJS 的中后台项目。"

**执行过程：**

1. 识别用户类型 → 专家模式（逐层确认关键分歧点，推荐项标注"推荐"）
2. 规模分级 → M 级默认
3. 项目类型判定 → 全栈 Web
4. 每层一个 `ask_followup_question`，候选 5-8 个，用户快速勾选
5. 前端选完 → 前端配套插件收尾 → 后端选型 → 后端配套插件收尾 → 跨端关注点
6. 每轮确认后输出进度摘要，全部完成后输出技术栈汇总

**输出：**

```
## 选型进度 [6/12 前端层级已完成]
✅ 前端-主框架: React
✅ 前端-开发语言: TypeScript
✅ 前端-构建工具: Vite
✅ 前端-UI 组件库: Ant Design
⬜ 前端-CSS 方案: 待选
...
```

## 示例 4：已有项目反向分析

**触发语：**
> "分析一下这个仓库的技术栈并给出优化建议。"

**执行过程：**

1. 读取项目元信息（README / .agent / package.json 等）
2. 分析目录结构（识别架构模式，是否符合规模分级）
3. 分析技术栈（对照兼容性矩阵检查不兼容组合、版本是否过时）
4. 分析代码质量（Lint / 测试 / 环境变量 / 硬编码敏感信息）
5. 分析公共能力复用（是否有 core/ 层、业务是否直连底层库）
6. 输出反向分析报告

**输出：**

```
## 项目反向分析报告
### 2. 技术栈画像
| 层 | 选型 | 版本 | 最新版本 | 状态 |
|----|------|------|----------|------|
| 前端-主框架 | Vue 2 | 2.7.x | 3.x | ⚠️ 过时 |
| 后端-框架 | Express | 4.x | 5.x | ⚠️ 过时 |
...
### 5. 问题清单
| # | 问题 | 严重度 | 建议方案 |
|---|------|--------|----------|
| 1 | Vue 2 已停止维护 | 高 | 迁移至 Vue 3 + Vite |
...
### 8. 优化建议（按优先级排序）
1. **P0（必须修复）** — ...
2. **P1（建议修复）** — ...
```
